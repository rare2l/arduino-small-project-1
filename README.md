#Objective:

The goal of this project was to create a simple LED control system using an Arduino Uno. The circuit includes 3 LEDs connected through resistors, and the Arduino is programmed to blink them in sequence.

⸻

Materials Used:

•	Arduino Uno – microcontroller
•	3 LEDs – red, green, and blue
•   3 Resistors (220Ω) – to limit current to each LED
•	Breadboard – for easy circuit assembly
•	Jumper Wires – for connections
•	Arduino IDE – to upload the code

⸻

What We Did:

1.	Connected each LED in series with a resistor to digital pins (e.g., pins 8, 9, and 10) on the Arduino.
2.	Wrote Arduino code to:
	•	Turn on each LED one by one.
	•	Keep each LED on for a short delay (e.g., 500ms).
	•	Turn them off before moving to the next.
3.	Uploaded the code to the Arduino via USB.
4.	Tested the circuit to ensure all LEDs blinked in the intended sequence.

⸻

Skills Applied:

 •	Understanding of basic electrical components 
 •	Circuit building with breadboard
 •	Arduino pin configuration
 •	Programming with digitalWrite and delay in Arduino IDE
